# BonAppétit ! v1.0

Des dîners de la semaine, pile dans ton budget. **Gratuit. Sans abonnement.**

## Lancer en local

```bash
cd web
npm install
npm run dev
```

→ [http://localhost:3000](http://localhost:3000)

## Parcours

1. Landing → **Créer mon menu**
2. Quiz (magasin, budget, goûts…)
3. Génération → Reveal (accès libre)
4. Espace `/menu` : semaine, courses, recettes, favoris

## Stack

- Next.js (App Router) + TypeScript + Tailwind
- Zustand (localStorage)
- Catalogue FR seed dans `web/src/data/`
